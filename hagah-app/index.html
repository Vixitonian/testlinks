Connect to your Supabein project

Your recordings can be saved to your own Supabein backend so they show up in your library on any device. This is optional — recording, mixing and MP3 export all work offline without it. Your token is stored only in this browser (localStorage) and is sent only to supabein.dxinnovationhub.com.

Preloaded voice (English only, for now)

"Quick preview" plays an approximate version through this device's own built-in voice, instantly. "Generate narration" runs a real neural text-to-speech model (Piper) entirely in this browser tab via WebAssembly — no server, no API key, works on any device. The first time you use a given voice it downloads a one-time model file (~60MB) and caches it in this browser for next time.
